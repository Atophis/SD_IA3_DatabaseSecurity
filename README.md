# SD_IA3_DatabaseSecurity

DynamoDB:

To run the code:
To use DynamoDB, you need to first register an account for AWS. You also need to setup the environment in vscode with "python3 -m venv .venv" and "source ./.venv/bin/activate". You have to "python3 -m pip install boto3" to get access to boto3.
The database is currently on my account and I would have to add permissions. You can create your own dynamoDB under your account and create a table with the same name as the one in the file to test it.

When you have your account, you need to get an Access Key thing, and connect that to your terminal. It is part of the AWS Cli process and you can learn more by looking it up. It should also be in the intro part of the Youtube tutorial link.
